Ethernet

Setup Wi-Fi

Starts on its own when the Ethernet link is down for the start delay, when BOOT is held 3 s, or from Maintenance.

While the setup Wi-Fi runs, and until the next restart, the LED outputs are limited to about 1600 RGBW (2100 RGB) LEDs in total instead of about 4100: the Wi-Fi takes that memory. With "On after each start" this applies after every start, also once the Wi-Fi has switched off again.

Apply

Changing name, password or Wi-Fi channel disconnects devices on the setup Wi-Fi, including this one if you use it. The reply may then never arrive.

LED strip

Input protocol

Two Art-Net sources on one universe

HTP (Art-Net default): the higher value of the two sources wins, per channel. LTP: the latest packet wins. Sources are told apart by IP address; a third is ignored, and a source silent for 10 s drops out. Consoles can switch this with ArtAddress.

LED type

The order the strip expects on its data line; white (if any) is always last. WS2812 is usually GRB, SK6812 RGBW usually GRB(W).

Outputs

Per-output options

Empty type or order = the setting above. Grouping: one DMX pixel lights that many LEDs. Offset: LEDs at the start that stay dark. Reverse: the first pixel goes to the far end. DMX start: channel of the first pixel in the first universe (the next universes start at 1); lets small strips share a universe.

LED timing

Presets hold bit time, pulse shape and latch and are stored on the board. Choosing one fills the fields; press Save below to use it.

ns

Only shapes the output sends exactly are listed: a pulse is a whole number of I2S samples, 4 per bit (8 per bit from 1000 ns up). The shape decides whether the LEDs tell a 0 from a 1; it does not change the speed. If neighbouring LEDs flicker, try a longer 0 or a shorter 1.

Firmware update

Install into this slot keeps the other slot (e.g. WLED) as it is: the board restarts into a small updater, which takes the file and writes it over the running firmware. The running version is replaced for good, so there is no rollback to it; if the new one fails to start, the board starts the other slot.

Takes 15–30 s, then the board restarts. Keep this page open. If the file picker does not open (Android’s “sign in” window), use your normal browser.

Maintenance

BOOT button on the board: click for the next test pattern (rainbow, chase, blackout, off). Click three times within 2 s (light turns white) to start the other firmware slot. Hold 3 s (light turns blue) for the setup Wi-Fi. Hold 10 s (light blinks red) to reset the password and network settings to defaults (DHCP); the name and LED settings stay.

Backup

All settings as a text file, without the password. Restoring applies them at once and keeps the current password.

Diagnostics

For troubleshooting: raw data from the API, the other firmware's log, and actions to test things.
